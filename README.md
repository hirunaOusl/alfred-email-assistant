# Alfred AI Email Assistant

An AI-powered email processing workflow built
using Python, LangGraph, and Google Gemini.

## Features

- Read incoming emails
- Classify emails as spam or legitimate
- Identify email categories
- Generate professional email replies
- Notify the email owner with generated drafts

## Tech Stack

- Python
- LangGraph
- Google Gemini API
- LangChain
- python-dotenv
